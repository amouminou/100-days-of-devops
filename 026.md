# Git Remote Update – xFusionCorp Games Repo

This document describes the steps taken to update Git remotes and push changes for the xFusionCorp games project.

## Repository Details

- **Local Repository Path:** `/usr/src/kodekloudrepos/games`
- **New Remote Repository:** `/opt/xfusioncorp_games.git`
- **New Remote Name:** `dev_games`
- **Branch:** `master`

---

## Steps Performed

### 1. Navigate to the Repository
```bash
cd /usr/src/kodekloudrepos/games
```

### 2. Add New Git Remote

A new remote named `dev_games` was added and pointed to the required repository.

```bash
git remote add dev_games /opt/xfusioncorp_games.git
```

**Verification:**
```bash
git remote -v
```

### 3. Copy Required File into Repository

The file `index.html` was copied from `/tmp` into the repository.

```bash
cp /tmp/index.html .
```

### 4. Commit Changes to Master Branch

```bash
git checkout master
git add index.html
git commit -m "Add index.html to games repository"
```

### 5. Push Changes to New Remote

The master branch was pushed to the newly added `dev_games` remote.

```bash
git push dev_games master
```
