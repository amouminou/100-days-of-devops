Go to the repository directory

cd /usr/src/kodekloudrepos/demo


Make sure you’re on the master branch

git checkout master


Create a new branch from master

git checkout -b xfusioncorp_demo


(Optional but recommended) Verify the branch

git branch


You should see xfusioncorp_demo highlighted as the current branch.

Takeaway from this lesson:

Use branches to safely develop new features without affecting the main (master) code.

Always start from the correct base branch (here, master) before creating a new one.

git checkout -b <branch-name> lets you create and switch to a new branch in one step.

Verifying your branch ensures you’re working in the right context before making changes.

In short: branching = clean workflow + safer development.
