# Cherry-Pick Commit from feature to master

## Repository Details

- **Repository Path:** `/opt/blog.git`
- **Clone Location:** `/usr/src/kodekloudrepos/blog`
- **Branches:** `master`, `feature`

## Objective

Merge **only one specific commit** from the `feature` branch into the `master` branch.

- **Commit message to merge:** `Update info.txt`

## Steps to Accomplish the Task

### 1. Navigate to the repository

```bash
cd /usr/src/kodekloudrepos/blog
```

### 2. Switch to the master branch

```bash
git checkout master
```

### 3. Identify the required commit from the feature branch

```bash
git log feature --oneline
```

Locate the commit with the message: `Update info.txt`

Copy the corresponding commit hash.

### 4. Cherry-pick the commit into master

```bash
git cherry-pick <commit-hash>
```

If conflicts occur:

```bash
git status
# resolve conflicts
git add .
git cherry-pick --continue
```

### 5. Push the changes to the remote repository

```bash
git push origin master
```

## Result

- The `Update info.txt` commit is successfully merged into `master`
- The `feature` branch remains unchanged
- Changes are pushed to the remote repository

## Takeaway

This lesson demonstrates how to merge a single specific commit from one branch into another without merging the entire branch. Using `git cherry-pick` allows developers to selectively apply changes, keep incomplete work isolated, and maintain a clean and stable master branch while development continues on feature branches.
