# Configure Nginx + PHP-FPM Using Unix Socket

Deploying a PHP Application Using Nginx + PHP-FPM (Version 8.1) on Nautilus Infrastructure

In today’s session, we will walk through a complete, end-to-end setup of a PHP-based application on the Nautilus infrastructure inside the Stratos DC. The development team has handed off a set of infrastructure requirements, and our goal is to transform those requirements into a properly functioning environment on App Server 1 (stapp01).

This lecture is very practical and mirrors real-world DevOps tasks involving PHP-FPM and Nginx integration.

## 1. Understanding the Requirements

Before writing a single command, let's break down the four core requirements and understand their significance.

### Requirement A — Install & Configure Nginx

Nginx must listen on port 8098, not the default port 80.

It must serve content from /var/www/html, which will host the application’s index.php and info.php.

This means we must modify or create a server block (virtual host) in Nginx.

### Requirement B — Install PHP-FPM 8.1

PHP-FPM stands for FastCGI Process Manager.

It allows PHP to run externally from Nginx.

Nginx never executes PHP directly; it always talks to PHP-FPM through:

a TCP port, OR

a UNIX socket.

The dev team requires PHP-FPM to expose a UNIX socket at:

/var/run/php-fpm/default.sock


This is NOT the default location, so we must update the PHP-FPM pool configuration accordingly.

### Requirement C — Integrate PHP-FPM with Nginx

This is the heart of the task.

Nginx must:

recognize .php files,

forward them to the PHP-FPM socket,

pass correct parameters (SCRIPT_FILENAME),

and receive executed output from PHP-FPM.

This is done using a location ~ \.php$ block inside the server configuration.

### Requirement D — Testing

Once everything is configured:

We test it from the jump host using curl.

The command must load the PHP application through Nginx on port 8098.

curl http://stapp01:8098/index.php


If we see PHP execution output, the setup is complete.

## 2. Installing Nginx

On App Server 1:

```bash
sudo yum install -y nginx
```


This installs:

The Nginx binary

Default configs under /etc/nginx

Systemd service files

After installation, Nginx is not yet configured for port 8098, so we must update its configuration.

## 3. Configuring Nginx Server Block

Edit the default server block:

```bash
sudo vi /etc/nginx/nginx.conf
```

Find the server { block and update:

```nginx
server {
    listen 8098;
    root /var/www/html;
    index index.php index.html index.htm;

    location / {
        try_files $uri $uri/ =404;
    }

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_pass unix:/var/run/php-fpm/default.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}
```


Why this matters:

- listen 8098 instructs Nginx to serve traffic on the custom port.
- root /var/www/html ensures the PHP app files are served.
- location ~ .php$ is the bridge between Nginx and PHP-FPM.
- fastcgi_pass defines the socket used for communication.

This aligns with the developer's desired application deployment environment.

📦 4. Installing PHP 8.1 and PHP-FPM

Default repositories may or may not include PHP 8.1 depending on the OS version.
If PHP 8.1 is not available, we enable Remi repository:

```bash
sudo yum install -y https://rpms.remirepo.net/enterprise/remi-release-8.rpm
sudo yum module reset php -y
sudo yum module enable php:remi-8.1 -y
sudo yum install -y php php-fpm php-cli php-common
```

After installation:

- PHP-FPM configuration lives under /etc/php-fpm.d/
- Main pool config is www.conf

## 5. Configuring PHP-FPM to Use the Required Socket

Open the PHP-FPM pool configuration:

```bash
sudo vi /etc/php-fpm.d/www.conf
```

Modify the listen directive:

```bash
listen = /var/run/php-fpm/default.sock
```

Create the parent directory if it doesn't exist:

```bash
sudo mkdir -p /var/run/php-fpm
sudo chown -R nginx:nginx /var/run/php-fpm
```

We also ensure the service runs under the nginx user:

```bash
user = nginx
group = nginx
```

**Why UNIX socket?**

A UNIX socket:

- is faster than TCP
- reduces overhead
- is commonly used in local Nginx–PHP-FPM setups

This improves performance in production environments.

## 6. Starting and Enabling Services

Enable and start both services:

```bash
sudo systemctl enable --now php-fpm
sudo systemctl enable --now nginx
```

Then restart to apply new configurations:

```bash
sudo systemctl restart php-fpm
sudo systemctl restart nginx
```

Verify their status:

```bash
sudo systemctl status php-fpm
sudo systemctl status nginx
```

At this stage:

- The socket should be active at /var/run/php-fpm/default.sock
- Nginx should be listening on port 8098

## 7. Testing the Configuration from the Jump Host

From the jump host, test using curl:

```bash
curl http://stapp01:8098/index.php
```

You should see rendered PHP output.

Test PHP info:

```bash
curl http://stapp01:8098/info.php
```

If PHP-FPM is correctly integrated, this will output the full PHP configuration matrix.
