Step-by-step solution
1. Go to the repository
cd /usr/src/kodekloudrepos/ecommerce


Make sure you’re on master and up to date:

git checkout master
git pull origin master

2. Create a new branch datacenter from master
git checkout -b datacenter

3. Copy the file into the repo

The file already exists on the server at /tmp/index.html.

cp /tmp/index.html .


(If the repo has a specific directory for HTML files, copy it there instead.)

4. Add and commit the file in datacenter branch
git add index.html
git commit -m "Add index.html to ecommerce repo"

5. Push the datacenter branch to origin
git push origin datacenter

6. Merge datacenter into master

Switch back to master:

git checkout master


Merge the branch:

git merge datacenter

7. Push the updated master branch to origin
git push origin master

✅ Final state checklist

✔ New branch datacenter created from master

✔ /tmp/index.html copied into the repo

✔ File committed in datacenter

✔ datacenter merged into master

✔ Both datacenter and master pushed to origin
