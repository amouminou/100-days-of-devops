Revert Latest Commit in Beta Repository
Task Description

The Nautilus application development team reported issues with recent commits in the Git repository located at:

/usr/src/kodekloudrepos/beta


The requirement is to revert the repository HEAD to the previous commit (the one with the initial commit message) by creating a new revert commit.

Steps to Revert the Latest Commit
1. Navigate to the repository
cd /usr/src/kodekloudrepos/beta

2. (Optional) Verify commit history
git log --oneline

3. Revert the latest commit (HEAD)
git revert HEAD --no-edit

4. Update the revert commit message
git commit --amend -m "revert beta"

5. Push the changes to the remote repository
git push origin master

Result

The latest commit has been reverted safely

A new commit is created with the message:

revert beta


Repository history remains intact
