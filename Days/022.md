# Day 22 — Clone a Local Bare Repository as the `natasha` User

## Overview
Clone the local bare repository at `/opt/blog.git` into the destination directory `/usr/src/kodekloudrepos/blog` while operating as the `natasha` user and without making permission or configuration changes.

---

## Steps

### 1) Switch to the `natasha` user

Make sure you are operating strictly as `natasha`:

```bash
sudo su - natasha
```

---

### 2) Verify the source repository exists

Confirm the repository is present and readable:

```bash
ls -ld /opt/blog.git
```

You should see it listed as a Git repository directory.

---

### 3) Ensure the destination directory exists

Verify (don't modify) the destination directory:

```bash
ls -ld /usr/src/kodekloudrepos
```

If it already exists, proceed to the clone step.

---

### 4) Clone the repository

Clone without changing permissions or configuration:

```bash
git clone /opt/blog.git /usr/src/kodekloudrepos/blog
```

This command:

- Uses the local bare repository as the source
- Copies it into `/usr/src/kodekloudrepos/blog`
- Preserves the repository structure
- Does not change permissions or configuration

---

### 5) Verify the clone

Check the cloned repository status:

```bash
cd /usr/src/kodekloudrepos/blog
git status
```

Expected output (example):

```
On branch <default-branch>
nothing to commit, working tree clean
```

---

## ✅ Final state

- Repository `/opt/blog.git` cloned successfully ✅
- Clone location: `/usr/src/kodekloudrepos/blog` ✅
- Task performed as `natasha` ✅
- No unauthorized changes or permission modifications made ✅

---

## 🔑 Key takeaways

- The source is a local bare repo at `/opt/blog.git`.
- Clone to `/usr/src/kodekloudrepos/blog` using `git clone /opt/blog.git /usr/src/kodekloudrepos/blog`.
- Perform actions as the `natasha` user and avoid altering permissions.
- Successful cloning is confirmed when `git status` shows a clean working tree.

**One-liner:** Clone the bare repo locally, preserve its structure, and do not change permissions: `git clone /opt/blog.git /usr/src/kodekloudrepos/blog`.
