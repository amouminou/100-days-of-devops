# Apache setup for hosting two static websites on port 3004

This guide shows how to prepare App Server 1 to host two static sites (`/beta` and `/cluster`) with Apache listening on port `3004`. It covers installation, configuration, deployment, permissions, and validation.

## Prerequisites
- CentOS/RHEL (or any system using `yum`/`httpd`)
- SSH access to the jump host and App Server 1
- Website directories backed up on the jump host (e.g., `/home/thor/beta` and `/home/thor/cluster`)

## 1. Install and enable Apache
Run on App Server 1:
```bash
sudo yum install -y httpd
sudo systemctl enable --now httpd
```
Enabling ensures Apache starts on boot.

## 2. Configure Apache to listen on port 3004
Edit the main Apache config:
```bash
sudo vi /etc/httpd/conf/httpd.conf
```
Find (or add) the Listen directive and set:
```
Listen 3004
```
Restart Apache:
```bash
sudo systemctl restart httpd
```

## 3. Transfer and deploy website files
From the jump host, copy the site folders:
```bash
scp -r /home/thor/beta tony@stapp01:/tmp/
scp -r /home/thor/cluster tony@stapp01:/tmp/
```
On App Server 1, move them into the document root:
```bash
sudo mv /tmp/beta /var/www/html/
sudo mv /tmp/cluster /var/www/html/
```

## 4. Set correct permissions
Give Apache ownership and readable permissions:
```bash
sudo chown -R apache:apache /var/www/html/
sudo chmod -R 755 /var/www/html/
```
- Ownership: ensures Apache can access files.
- `755`: allows global read/execute but restricts write.

## 5. Configure Apache Aliases
Create or edit a site config:
```bash
sudo vi /etc/httpd/conf.d/sites.conf
```
Add:
```apache
Alias /beta /var/www/html/beta
<Directory /var/www/html/beta>
    Require all granted
</Directory>

Alias /cluster /var/www/html/cluster
<Directory /var/www/html/cluster>
    Require all granted
</Directory>
```
Restart Apache:
```bash
sudo systemctl restart httpd
```

> Note: Aliases are simpler than separate VirtualHosts for multiple static sites served from the same host and port.

## 6. Validation
On App Server 1, test with curl:
```bash
curl http://localhost:3004/beta/
curl http://localhost:3004/cluster/
```
A successful response returns each site’s HTML homepage.

## Troubleshooting & tips
- If curl times out, confirm `httpd` is running and listening on 3004:  
  `sudo ss -tlnp | grep 3004` or `sudo netstat -tlnp | grep 3004`
- SELinux: If enabled, you may need to adjust contexts:
```bash
sudo restorecon -R /var/www/html
sudo chcon -R -t httpd_sys_content_t /var/www/html
```
- Firewall: ensure port 3004 is allowed if testing remotely:
```bash
sudo firewall-cmd --add-port=3004/tcp --permanent
sudo firewall-cmd --reload
```

## Key takeaways
- Aliases allow hosting multiple static sites without separate virtual hosts.
- Serving on port 3004 is common for internal/dev-only setups.
- File ownership/permissions and SELinux/firewall rules are common causes of issues.
- Use `curl` and `ss`/`netstat` for quick validation.
