Apache Static Website Deployment (Port 3004)

This project prepares App Server 1 to host two static websites—beta and cluster—using Apache on a custom port (3004). The setup includes installation, configuration, content transfer, permissions, and validation.

🚀 Overview

This environment supports early-stage development where application code is still being built, but infrastructure must be production-ready. Apache is configured using Alias directives to expose multiple static websites without requiring separate VirtualHost configurations.

1️⃣ Install and Enable Apache
sudo yum install -y httpd
sudo systemctl enable --now httpd

Apache is now installed, enabled, and running.

2️⃣ Configure Apache to Listen on Port 3004

Open the Apache configuration file:

sudo vi /etc/httpd/conf/httpd.conf

Update the Listen directive:

Listen 3004

Restart Apache to apply the change:

sudo systemctl restart httpd
3️⃣ Transfer Website Content

From the jump host, copy site backup directories:

scp -r /home/thor/beta tony@stapp01:/tmp/
scp -r /home/thor/cluster tony@stapp01:/tmp/

Move the directories into Apache’s document root:

sudo mv /tmp/beta /var/www/html/
sudo mv /tmp/cluster /var/www/html/
4️⃣ Set Correct Permissions

Ensure Apache can read and serve both websites:

sudo chown -R apache:apache /var/www/html/
sudo chmod -R 755 /var/www/html/
5️⃣ Configure Apache Aliases

Create or modify the site configuration file:

sudo vi /etc/httpd/conf.d/sites.conf

Add the alias directives:

Alias /beta /var/www/html/beta
<Directory /var/www/html/beta>
    Require all granted
</Directory>


Alias /cluster /var/www/html/cluster
<Directory /var/www/html/cluster>
    Require all granted
</Directory>

Restart Apache:

sudo systemctl restart httpd
6️⃣ Validation

Test that both websites load correctly:

curl http://localhost:3004/beta/
curl http://localhost:3004/cluster/

If successful, each command returns HTML output from the respective site.

📌 Key Takeaways

Apache can host multiple static sites with Alias directives.

Serving on a custom port (3004) is common in internal and development environments.

Correct ownership and permissions are essential for Apache to serve files.

curl offers a quick, reliable way to validate service functionality.

This setup enables infrastructure readiness before application development is complete.
