Apache Setup for Hosting Two Static Websites on Port 3004

This guide covers the full process of preparing App Server 1 to host two static websites—beta and cluster—using Apache. It walks through installation, configuration, content deployment, permissions, alias setup, and validation.

1️⃣ Install and Enable Apache

Apache (httpd) must be installed and running before any website can be hosted.

sudo yum install -y httpd
sudo systemctl enable --now httpd


Enabling the service ensures Apache automatically starts on every system boot.

2️⃣ Configure Apache to Listen on Port 3004

Open the main Apache configuration file:

sudo vi /etc/httpd/conf/httpd.conf


Locate the existing Listen directive and update it:

Listen 3004


This instructs Apache to accept HTTP traffic on port 3004 instead of the default port 80.

Restart the service to apply changes:

sudo systemctl restart httpd

3️⃣ Transfer and Deploy Website Files

From the jump host, copy the website backup folders to App Server 1:

scp -r /home/thor/beta tony@stapp01:/tmp/
scp -r /home/thor/cluster tony@stapp01:/tmp/


On App Server 1, move the files to Apache’s document root:

sudo mv /tmp/beta /var/www/html/
sudo mv /tmp/cluster /var/www/html/

4️⃣ Set Correct Permissions

Apache requires read access to serve files properly.

sudo chown -R apache:apache /var/www/html/
sudo chmod -R 755 /var/www/html/


Ownership ensures Apache controls these directories.

755 allows global read/execute while keeping write restricted.

5️⃣ Configure Apache Aliases

Instead of virtual hosts, Apache can expose multiple sites using Alias directives.

Create or edit:

sudo vi /etc/httpd/conf.d/sites.conf


Add the following:

Alias /beta /var/www/html/beta
<Directory /var/www/html/beta>
    Require all granted
</Directory>

Alias /cluster /var/www/html/cluster
<Directory /var/www/html/cluster>
    Require all granted
</Directory>


Restart Apache:

sudo systemctl restart httpd

6️⃣ Validation on App Server 1

Use curl to verify that Apache is serving both sites correctly:

curl http://localhost:3004/beta/
curl http://localhost:3004/cluster/


A successful response returns each site’s HTML homepage.

📌 Key Takeaways

Aliases allow Apache to host multiple static sites without separate virtual hosts.

Serving on port 3004 is common for internal or development environments.

File ownership and permissions are essential—Apache must be able to read directories.

curl provides the quickest feedback loop to ensure the service is responding as expected.

This setup prepares infrastructure ahead of development, reducing deployment complexity later.
